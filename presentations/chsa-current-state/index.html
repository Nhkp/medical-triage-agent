Scope and safety boundary

Assist, never replace

Should support

  • Collect patient-declared symptoms.
  • Structure relevant context.
  • Escalate red-flag signals.
  • Explain priority with an audit ID.

Must not do

  • Make autonomous diagnoses.
  • Prescribe or discharge.
  • Hide uncertainty.
  • Replace clinician judgment.
This slide should be crisp. It is central to stakeholder trust.

Step 3 · Deployment path

FastAPI wraps vLLM with stable triage and audit endpoints

GET /healthservice and model readiness
POST /triagesymptoms → priority, explanation, audit ID
GET /audit/{id}metadata-only trace, no raw patient text

Fallback rules validate the API without GPU; vLLM enables model-backed explanations on a GPU host or Colab runtime.
